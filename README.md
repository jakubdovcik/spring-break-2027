# spring/27

A small dashboard for choosing a spring-break trip (12–21 March 2027): route maps, stays, Michelin tables, weather and flights for each option.

- All trip content lives in `data.js`. Edit it to add or change options.
- Ratings and notes save in your own browser. **Notes → Copy share link** sends them to someone else.
- Static site: Leaflet + Esri light-gray tiles, with photos pulled live from Wikipedia.
